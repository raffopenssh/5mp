6. THE REQUEST FLOW (Typical interaction)
─────────────────────────────────────────────

    User clicks park
          │
          v
    showParkPopup('CAF_Chinko')
          │
          v
    fetch('/api/parks/CAF_Chinko/stats?pwd=test2026')
          │
          v
    handleParkStats() in srv/api.go
          │
          v
    SELECT * FROM parks WHERE id = 'CAF_Chinko'
          │
          v
    Return JSON: {area, fires, settlements}
          │
          v
    renderParkStats(data)
          │
          v
    Update DOM (popup appears)

    ────────────────────────────────────────

    User clicks "Fire" accordion
          │
          v
    openAccordionSection('fire')
          │
          v
    Check: if (!section.dataset.loaded)
          │
          v
    fetch('/api/parks/CAF_Chinko/fire-narrative?pwd=test2026')
          │
          v
    handleFireNarrative() in srv/narrative_handlers.go
          │
          v
    SELECT narrative FROM fire_narrative_cache
          │
          v
    Return JSON: {narrative, stats}
          │
          v
    renderNarrative(data)
          │
          v
    Insert into accordion content
          │
          v
    Set: section.dataset.loaded = 'true'

8. THE CONTEXT ENGINE (Narrative enrichment)
───────────────────────────────────────────────

    Fire at (10.5, 18.2)
           │
           v
    buildFireContext()
           │
           ├─── Query park_rivers (HydroRIVERS)
           │    → "3km north of Chinko River"
           │
           ├─── Query data/roads_heigit/*.json
           │    → "along dirt road"
           │
           ├─── Query park_settlements
           │    → "near Koundi village"
           │
           ├─── Query osm_places
           │    → "10km from ranger camp"
           │
           ├─── Query park_climate
           │    → "dry season fire pattern"
           │
           └─── Query fire_detections (historical)
                → "recurring fire site"
           │
           v
    Generate narrative with context
           │
           v
    "Fire detected 3km north of Chinko River,
     near Koundi village, along dirt road to
     ranger camp. Dry season fire pattern.
     This is a recurring fire site (5 times
     in past 2 years)."
