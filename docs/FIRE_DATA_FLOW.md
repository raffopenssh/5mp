# Fire Data Flow - NRT Cron Job

## Daily Pipeline (3am UTC)

```
daily_fire_update.py --days 5
```

### Step-by-Step Flow:

#### 1. **Download NRT Fires** (Last 5 days)
- Source: NASA FIRMS API
- Downloads: VIIRS_NOAA20_NRT fires
- Coverage: Africa bbox (-20,-35,55,40)

#### 2. **Insert to Database** (UPSERT - No Duplicates)
```sql
INSERT OR REPLACE INTO fire_detections (...)
```
- Table: `fire_detections` (6M+ records)
- Unique constraint: prevents duplicates
- This is the **source of truth**

#### 3. **Update Raw JSON Files** (APPEND with deduplication)
- Location: `data/raw-fire-viirs-20200101-20260222/*.json`
- Logic:
  ```python
  if raw_file.exists():
      load existing fires
      existing_keys = set of (lat, lon, date, time)
      
  for new_fire in downloaded_fires:
      if (lat, lon, date, time) not in existing_keys:
          append to existing_fires
  
  write entire list (with open(file, 'w'))
  ```
- **Result: Appends new fires, no duplicates**

#### 4. **Rebuild Fire Groups** (--incremental)
```bash
rebuild_fire_trajectories_v5.py --incremental --days 14
```
- Output: `data/fire_groups_v5/*.json` (162 files)
- Logic:
  ```python
  # Read fires from database (last 14 days)
  fires = db.query("WHERE acq_date >= cutoff")
  
  # Cluster into groups using DBSCAN
  new_groups = cluster_fires(fires)
  
  # Merge with existing groups
  if incremental and json_file.exists():
      old_groups = load_json()
      keep_old = [g for g in old_groups if g['end_date'] < cutoff]
      groups = keep_old + new_groups  # Old preserved, recent replaced
  
  # Overwrite file
  with open(json_file, 'w') as f:
      json.dump(groups, f)
  ```
- **Result: Old groups preserved, recent groups updated**

#### 5. **Load Groups to Database**
```bash
load_fire_groups_to_db.py --incremental --days 14
```
- Reads from `fire_groups_v5/*.json`
- Loads to `feature_geometries` table
- Updates fire trajectory geometries

#### 6. **Update Narratives**
```bash
precompute_narratives_v5.py --incremental --days 14
```
- Updates `fire_narrative_cache` table
- Pre-computes fire analysis text

#### 7. **Create Notifications**
- Generates notifications for significant fire activity
- Stored in `notifications` table

## Data File Behavior Summary

| File Type | Location | Append? | How? |
|-----------|----------|---------|------|
| **Database** | `db.sqlite3` | ✅ Yes | UPSERT (no duplicates) |
| **Raw JSON** | `data/raw-fire-viirs-*/*.json` | ✅ Yes | Deduplicates by (lat,lon,date,time) |
| **Groups v5** | `data/fire_groups_v5/*.json` | ⚠️ Hybrid | Keeps old groups, replaces recent |
| **NRT** | `data/fire_nrt/*_nrt.json` | ❓ Unknown | Not touched by daily cron |

---

## Key Points:

### ✅ **No Duplicates**
- Database: UPSERT with unique constraint
- Raw JSON: Deduplication by key tuple
- Groups JSON: Temporal partitioning (old vs recent)

### ⚠️ **NRT JSON Files**
- `data/fire_nrt/*_nrt.json` are **NOT updated by the cron job**
- Last modified: Feb 28 04:35 (not at 3am cron time)
- Likely generated by a separate process or manual script

### 🔄 **Incremental Logic**
- Database: Always incremental (UPSERT)
- Raw JSON: Always incremental (append + dedupe)
- Groups JSON: Hybrid (preserve old, rebuild recent)
- 14-day window for incremental rebuilds
